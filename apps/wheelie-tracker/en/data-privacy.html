Privacy Policy for the App “Wheelie”

Last updated: May 2026

1. Controller

The controller responsible for data processing within this app is:

MANNABRI UG (haftungsbeschränkt)
Otto-Dix-Straße 9
67105 Schifferstadt
Email: info@mannabri.de

No data protection officer has been appointed.

2. Types of data processed

The app processes only the following data:

  • Pitch angle / orientation values
  • GPS location data
  • Timestamps of measurements

No metadata, device identifiers, telemetry data, or crash logs are collected or transmitted to third parties.

The data is generally stored locally on the device.

3. Purposes of processing

The data is processed for the following purposes:

  • Detecting wheelies.
  • Displaying and evaluating rides within the app.
  • Creating and managing statistics within the app.
  • Exporting ride data as a JSON file at the user’s request.

No use is made for advertising, profiling, or analytics purposes.

4. Legal bases

Processing is based on:

  • Article 6(1)(b) GDPR, insofar as data processing is necessary to provide and use the app’s functions.
  • Article 6(1)(a) GDPR, insofar as location data is processed on the device only after consent has been given.

Location access is used only if the user grants the relevant permission.

5. Recipients and third parties

No personal data is shared with third parties.

In particular:

  • no server or cloud connection by the provider,
  • no analytics services,
  • no tracking services,
  • no advertising services,
  • no profiling,
  • no transfers to third countries.

The app does not use external services to transmit or evaluate the data.

6. Storage period

The data is stored exclusively locally on the device.

It remains there until it is deleted within the app or the app is removed from the device.

After uninstallation, locally stored data is generally deleted. Note: Depending on the device settings, local app data may be included in device backups, in particular iCloud backups. The provider has no access to these backups.

7. Location data

The app uses location data exclusively:

  • to record rides,
  • only locally on the device,
  • only while the app is in use,
  • without transmission to third parties.

When the location feature is started for the first time, iOS asks for permission to use location services.

Only the “While Using the App” permission is used. Location data is not used in the background.

The permission can be revoked at any time in the iOS settings.

8. Export of ride data

Users can export ride data as a JSON file.

The export takes place only at the user’s request. The file created in this process is not automatically transmitted to the provider or to third parties unless the user shares or stores it themselves.

9. Data subject rights

Data subjects have the following rights under the GDPR:

  • Right of access,
  • Right to rectification,
  • Right to erasure,
  • Right to restriction of processing,
  • Right to object,
  • Right to data portability,
  • Right to withdraw consent with effect for the future.

Since the data is processed exclusively locally on the device, most rights can be exercised directly by deleting the data or uninstalling the app.

Requests regarding data protection rights can be sent to info@mannabri.de.

10. Data security

The app does not transmit any data to external servers and does not store any data in its own cloud infrastructure.

No additional encryption of app data is implemented by the provider. The security of locally stored data therefore depends primarily on the security mechanisms of the iOS device used and the system settings selected there.

The app itself has no access to iCloud backups or other backup processes initiated by the operating system.

11. Changes to this Privacy Policy

The controller reserves the right to amend this Privacy Policy as necessary so that it always reflects the actual technical and legal circumstances.

The current version is available in the app or at the designated location.
