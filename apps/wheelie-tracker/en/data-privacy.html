Privacy Policy for the App "Wheelie"

Last updated: 2026

2. Types of Data Processed

The app processes exclusively the following data:

  • Device sensor data (tilt / device orientation)
  • GPS location data
  • Timestamps of measurements

This data is stored locally on the device only and is not transmitted.

3. Purpose of Processing

Data processing is carried out to:

  • detect wheelies
  • display ride recordings locally
  • provide statistics within the app

The data is not transmitted, processed, or linked for profiling, advertising, or analytics purposes.

4. Legal Basis

Processing is carried out on the basis of:

  • Art. 6(1)(b) GDPR (performance of contract), as the app cannot function without this data, or
  • Art. 6(1)(f) GDPR (legitimate interest), as the processing is technically necessary for the app to function correctly.

5. No Sharing, No Tracking, No Cloud Services

None of the following activities take place:

  • No sharing of data with third parties
  • No server or cloud connection
  • No analytics or tracking services
  • No advertising
  • No profiling
  • No transfer to third countries

The data remains exclusively on the user's device.

6. Storage Location and Retention Period

  • All data is stored exclusively locally on the device.
  • The data remains stored until the user:
    • deletes it within the app, or
    • uninstalls the app from the device.

After uninstallation, all data is deleted.

7. Location Data

The app uses location data only:

  • for recording rides
  • locally on the device
  • only while the feature is in use
  • without transmission to third parties

On first launch, iOS will request permission to use location data.

8. Rights of Data Subjects

Users have the following rights under GDPR:

  • Right of access
  • Right to rectification
  • Right to erasure ("right to be forgotten")
  • Right to restriction of processing
  • Right to data portability
  • Right to object

Since the app stores data only locally, all rights can be exercised directly on the device by the user (e.g. delete data or remove the app).

9. Data Security

Since no data is transmitted to external servers or stored externally by the provider, data security is limited to:

  • the security of the user's device,
  • the security of the storage mechanisms provided by the operating system,
  • and the technical integrity of the app.

The app itself does not use any cloud services or external servers for data storage.

Depending on the device's system settings, locally stored app data may, however, be included in automatic device backups (e.g. iCloud backups by Apple). The app provider has no access to these backup processes.

10. Changes to this Privacy Policy

I reserve the right to update this privacy policy as necessary.
